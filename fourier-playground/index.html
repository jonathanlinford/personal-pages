ABOUT THE PLAYGROUND

A Fourier transform sorts a signal by frequency.

A signal can be a sound, an image row, a heartbeat, or any value that changes. The Fourier transform asks which repeating patterns are hiding inside it.

This lab uses a discrete Fourier transform. The same basic method appears in audio compression, medical imaging, radio, and astronomy.
